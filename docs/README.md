# Documentation site

GitHub Pages publishes this directory as a static site.

The main tutorial lives in `tutorials/attention-kernel-walkthrough/`. It is intentionally self-contained: runtime JavaScript, generated teaching data, verification summaries, KaTeX assets, and reproducibility scripts stay beside the page. Local/private implementation trees are referenced by component name only and are not copied into the public site.

The [2026-11-11 tutorial audit](tutorials/attention-kernel-walkthrough/audit.md) records corrected U1 position/mask semantics, synthetic-fixture limits, and CPU reproduction commands.

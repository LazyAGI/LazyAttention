依据、范围与读图约定

本页固定讲解 MoT 的 CP=1、本地 FFA forward、auto_range_merge=False、disable_fwd_atomic_reduction=False。真实形状和 ranges 来自此前保存的 workload；不是新采集的执行 trace。通用 Attention 页使用 8×8 的缩小教学网格。深蓝表示逻辑处理当前块，流水线中的 K/V 实际可交错预取。

二值 mask M=1 表示可见；加到 score 上的 B 为 0（可见）或 −∞（不可见）。ranges 的 attn_type=0 则表示 Full，attn_type=1 表示 causal，不能把这两个编码当成二值 mask。

  • 真实输入与 ranges 快照
  • MoT metadata → ranges 适配器：CPU 建计划，缓存复用；不是先在 GPU 建 N×N mask。
  • tile 选择；persistent 调度器
  • TMA / shared / 在线 softmax；锁与跨 slice 合并
  • FFA → fast_zero_fill 的 launch 顺序；输出 dtype 转换
  • NVIDIA：CTA 与 L2 / shared memory。不同 CTA 可以命中相同 L2 数据；本页不假设命中率，也不把 shared memory 画成跨 CTA 公共缓存。

QKᵀ 与 PV 在同一融合 kernel；中间整张 S/P 不落 HBM。Kᵀ 是运算视图，不代表存在一份完整的转置 K 张量。实际所有边界均采用左闭右开区间。
